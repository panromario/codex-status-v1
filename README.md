# UIS Codex Limit для IDE JetBrains

Плагин показывает `Codex 75%` в строке состояния — сколько осталось от 5-часового лимита ChatGPT/Codex. Полные данные по доступным периодам и времени сброса находятся в подсказке и меню виджета. Серый `Codex —` означает, что данные недоступны; старое значение не показывается как актуальное.

Цвет индикатора вычисляется по точному остатку, а процент отображается с округлением вниз:

- зелёный — израсходовано не больше 60% (осталось не меньше 40%);
- жёлтый — осталось от 10% включительно до 40%;
- красный — осталось меньше 10%.

Текущая версия: **2.0.9**. Она предназначена для IDE JetBrains на платформе **2026.2 / build 262** и новее: PhpStorm, PyCharm, IntelliJ IDEA, WebStorm, GoLand, CLion, RubyMine, DataGrip, Rider и других настольных IDE со стандартной строкой состояния IntelliJ Platform. Используется один ZIP для macOS, Windows и Linux. Android Studio и JetBrains Gateway отдельно не проверялись.

## Несколько аккаунтов

Нажмите на индикатор и выберите «Добавить аккаунт…». Укажите название и дату регистрации, затем завершите официальный вход OpenAI и 2FA в браузере, открытом Codex CLI. Для каждого аккаунта создаётся отдельный `CODEX_HOME` в `~/.codex/profiles/`. Плагин хранит название, email из авторизации, локальный идентификатор, путь, дату добавления и введённую дату регистрации; пароль и секрет 2FA не запрашиваются и не сохраняются.

При переключении плагин атомарно переносит `auth.json` выбранного профиля в основной `CODEX_HOME`. Обновлённая авторизация предыдущего аккаунта возвращается в его профиль, а исходный системный `auth.json` при первом переключении сохраняется как `auth.before-account-switch.json`. Последний локальный rollout синхронизируется между основным каталогом и профилем, чтобы его можно было продолжить после смены аккаунта.

В меню «Аккаунты» показываются остатки лимитов и расчётная дата окончания месяца с регистрации. Эта дата равна введённой дате плюс один календарный месяц и не является подтверждённой датой окончания подписки. За пять дней до неё в подсказке появляется предупреждение.

Пункт «Статистика токенов…» суммирует записи `last_token_usage` по дням из локальных JSONL-сессий выбранного `CODEX_HOME`: всего, входные, кэшированные, выходные и reasoning-токены. Тексты запросов и ответов не используются.

## Установка и обновление

1. Откройте Settings → Plugins → ⚙ → Install Plugin from Disk…
2. Выберите `dist/uis-codex-limit-2.0.9.zip`.
3. Подтвердите установку или обновление и перезапустите IDE, если она предложит.
4. Проверьте версию **2.0.9** в Settings → Plugins или в подсказке индикатора.

ID плагина не изменился, поэтому обновление заменяет предыдущую версию и сохраняет настройки. Строка состояния должна быть включена через View → Appearance → Status Bar. Виджет можно включить через её контекстное меню: `UIS Codex Limit: остаток лимита`.

## Codex CLI

Требуется Codex CLI с поддержкой `app-server` и авторизацией через ChatGPT (`codex login`). API-ключ OpenAI сам по себе не предоставляет сведения об остатке подписки ChatGPT.

Плагин сначала использует путь из настроек, затем ищет `codex` в PATH. На macOS и Linux дополнительно проверяются `/opt/homebrew/bin/codex`, `/usr/local/bin/codex` и `~/.local/bin/codex`. На Windows поддерживаются `codex.exe`, `codex.cmd`, `codex.bat`, npm-каталог `%APPDATA%\npm` и Node.js в `%LOCALAPPDATA%\Programs\nodejs`. Пути с пробелами поддерживаются. В настройках можно указать другой исполняемый файл и `CODEX_HOME`; `~/` разворачивается в домашний каталог.

Данные обновляются при запуске, после смены аккаунта и раз в 30 секунд. Запрос выполняется в фоне и ограничен 25 секундами. При закрытии проекта дочерний процесс сначала завершается штатно, затем принудительно, если не остановился. Для каждого открытого проекта работает собственный индикатор. Плагин не зависит от AI Assistant и не использует его внутренние API.

## Сборка и проверки

Сборка использует библиотеки и `javac` установленной IDE JetBrains, без Gradle и загрузки SDK:

```sh
python3 build.py --ide "$HOME/Applications/PhpStorm.app/Contents"
python3 build.py --ide "$HOME/Applications/PyCharm.app/Contents"
```

Путь также можно задать переменной `JETBRAINS_IDE_HOME`; `PHPSTORM_HOME` поддерживается для обратной совместимости. Нужны Python 3.8+, IDE build 262+ и её JBR с `javac`. На Windows передайте каталог установки IDE, на macOS — каталог `Contents`, на Linux — корень установки.

Скрипт компилирует Java 21 bytecode, проверяет версию SDK, запускает тесты квот, окружения CLI, профилей, дат, статистики, авторизации и восстановления rollout, затем создаёт `dist/uis-codex-limit-2.0.9.zip`. Библиотеки IDE и Codex CLI в архив не включаются.

После установки сравните процент с `/status` того же CLI, проверьте подсказку, меню аккаунтов, статистику и сообщение при неверном пути к CLI.

## Источник данных

Плагин использует официальный Codex App Server: JSON-RPC через stdin/stdout, методы `initialize`, `initialized` и `account/rateLimits/read`. Остаток рассчитывается как `100 - usedPercent`; при наличии выбирается 5-часовой период. Плагин не запускает задачи модели, не расходует лимит на генерацию и не записывает ответы сервера или stderr в журнал.

Интеграция со строкой состояния использует стандартный API IntelliJ Platform Status Bar Widgets.
