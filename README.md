# UIS Codex Limit для PhpStorm

Плагин показывает только `Codex 75%` в строке состояния — сколько осталось от 5-часового лимита ChatGPT/Codex. Название выбранного аккаунта, остальные периоды, местное время сброса и дата добавления аккаунта находятся в подсказке при наведении и в меню по клику. В меню «Аккаунты» под каждым подключением мелким шрифтом показываются даты сброса лимитов по периодам. При открытии меню данные запрашиваются для каждого аккаунта. Если до сброса осталось не больше 30 минут, дата зелёная; не больше часа — жёлтая; больше часа — красная. Через две недели после добавления там появляется уведомление; за пять дней до полного месяца — жёлтое предупреждение с числом оставшихся дней.

Отдельный пункт «Статистика токенов…» показывает расход по дням для локальных сессий выбранного аккаунта: всего, входные, кэшированные, выходные и reasoning-токены. Статистика строится только по записям usage в `CODEX_HOME/sessions`; тексты запросов и ответов не используются.

Цвета:

- Зелёный: израсходовано не больше 60% (осталось ≥40%).
- Жёлтый: осталось от 10% включительно до 40%.
- Красный: осталось меньше 10%.
- Серый `Codex —`: данные недоступны, включая отсутствие входа или ошибку сети. Старый остаток не выдаётся за актуальный.

Порог 60% трактуется как **расход**, а 10% — как **остаток**. Отображение целых процентов округляется вниз; цвет вычисляется по точному значению.

Текущая версия: **2.0.7**. Последующие выпуски увеличивают только последнюю часть номера. Название и версия отображаются в Settings → Plugins, подсказке индикатора и заголовках настроек. Наведите курсор на `Codex …`, чтобы увидеть `UIS Codex Limit v2.0.7`.

## Несколько аккаунтов

Нажмите на индикатор и выберите «Добавить аккаунт…». Задайте понятное название, затем завершите официальный вход OpenAI и 2FA в открывшемся браузере. После первого входа аккаунт появляется в подменю «Аккаунты» и переключается одним нажатием. Там же выбранный аккаунт можно переименовать или удалить вместе с его локальными данными авторизации.

Для каждого аккаунта создаётся отдельный `CODEX_HOME` в `~/.codex/profiles/`. Там сам Codex CLI хранит и обновляет свою авторизационную сессию. При выборе аккаунта плагин сначала мягко останавливает внешний ACP-процесс и даёт ему до 5 секунд на сохранение rollout текущего чата, затем атомарно активирует `auth.json` выбранного аккаунта в основном `~/.codex`. Старый чат остаётся в истории JetBrains. Если Codex не создал rollout (например, в чате выполнялись только локальные команды `/status`), плагин восстанавливает его из локальной истории AI Chat; после перезапуска агента можно продолжить тот же чат с новой авторизацией. Обновлённые токены предыдущего аккаунта возвращаются в его профиль, а исходный системный `auth.json` при первом переключении сохраняется как `~/.codex/auth.before-account-switch.json`.

Плагин сохраняет только название профиля, email, путь, идентификатор и дату добавления; пароль и секрет 2FA он не запрашивает и не хранит. Повторный `codex logout` / `codex login` при каждом переключении не нужен.

## Обновление

1. Откройте Settings → Plugins → ⚙ → Install Plugin from Disk…
2. Выберите `dist/uis-codex-limit-2.0.7.zip` в этом проекте.
3. Подтвердите обновление и перезапустите PhpStorm.
4. В Settings → Plugins найдите **UIS Codex Limit** и проверьте версию **2.0.7**. Она также видна при наведении на индикатор.

Идентификатор плагина сохранён, поэтому версия заменяет прежний Codex Limit Status и сохраняет настройки CLI и CODEX_HOME. Удалять старую версию перед обновлением не нужно.

## Установка

1. PhpStorm 2026.3 (build 263) или новее: Settings → Plugins → ⚙ → Install Plugin from Disk.
2. Выберите `dist/uis-codex-limit-2.0.7.zip` и перезапустите IDE, если она предложит.
3. Убедитесь, что строка состояния включена: View → Appearance → Status Bar. При необходимости включите `UIS Codex Limit: остаток лимита` в её контекстном меню.

Требуется установленный Codex CLI с поддержкой `app-server` и авторизацией через ChatGPT (`codex login`). API-ключ OpenAI сам по себе не предоставляет остаток подписки ChatGPT. Используется учётная запись выбранного CLI / CODEX_HOME; если агент JetBrains авторизован отдельно, выберите соответствующий CODEX_HOME.

Плагин ищет CLI в `/opt/homebrew/bin/codex`, `/usr/local/bin/codex`, `~/.local/bin/codex`, затем в PATH IDE. Любой клик по индикатору открывает все периоды лимитов и время сброса. Пункт «Настройки…» в этом окне позволяет указать другой исполняемый файл и CODEX_HOME. Путь вводится без кавычек и аргументов; поддерживается `~/`. CLI получает окружение оболочки, загруженное IDE. В PATH дополнительно включаются каталог CLI и стандартные каталоги Node.js (`/opt/homebrew/bin`, `/usr/local/bin`), чтобы npm-установка работала при запуске IDE из Dock. Пустой CODEX_HOME сохраняет окружение CLI (по умолчанию `~/.codex`).

При создании чата и событии `ChatSessionHostListener.chatTimestampUpdated` в AI Chat обновление запускается сразу, затем через 5, 15 и 30 секунд, чтобы учесть задержку серверного учёта. Если запрос лимитов уже выполняется, повторное обновление ставится в очередь. Резервное автообновление — раз в 30 секунд; клик любой кнопкой мыши показывает последние полученные лимиты без запроса обновления. Подписка использует внутренний API JetBrains AI Assistant 263.5153.42; после обновления AI Assistant интеграцию следует перепроверить. Без AI Assistant остаётся обновление по таймеру. Запрос выполняется в фоне и ограничен 25 секундами. При закрытии проекта процесс завершается. Для каждого открытого проекта работает свой индикатор.

## Сборка и проверки

Сборка использует библиотеки установленной IDE и её `javac`, без скачивания Gradle или SDK:

```sh
python3 build.py --ide "$HOME/Applications/PhpStorm.app/Contents"
```

Для сборки также нужен установленный AI Assistant: при другом расположении передайте `--ai-plugin /path/to/ml-llm`. Его библиотеки используются только при компиляции и не включаются в ZIP.

Альтернативный путь можно задать переменной `PHPSTORM_HOME`. Нужны Python 3.8+ и JBR с `javac`; на Linux укажите корень установки IDE. Компиляция использует Java 21 bytecode, минимальная заявленная версия платформы — 263. Совместимость с другими сборками отдельно не проверялась.

Скрипт компилирует плагин, запускает проверки границ цветов, выбора периода, обработки отсутствующих данных и создаёт установочный ZIP. Проверка отображения и жизненного цикла внутри запущенной IDE выполняется после установки: сравните цифры с `/status` того же CLI, проверьте подсказку, открытие всех лимитов левой, средней и правой кнопками мыши и поведение при неверном пути к CLI.

## Результат проверки

Версия 1.0.1 исправляет запуск npm-версии Codex из графической IDE с сокращённым PATH: раньше `/usr/bin/env node` завершался с кодом 127. Добавлены проверки поиска CLI, запуска через runtime из каталога CLI, сохранения CODEX_HOME и путей с пробелами. Подсказка различает завершение CLI, тайм-аут, ошибку RPC и ошибку запуска; ответы сервера не раскрываются.

Реальный локальный CLI успешно прошёл `initialize` и `account/rateLimits/read` вне песочницы сборки. В песочнице запуск блокируется запретом записи базы состояния в `~/.codex`. Отображение новой версии внутри IDE требует установки ZIP и перезапуска.

## Источник данных

Официальный [Codex App Server](https://learn.chatgpt.com/docs/app-server): JSON-RPC через stdin/stdout, `initialize`, `initialized`, затем `account/rateLimits/read`. Остаток рассчитывается как `100 - usedPercent`; используются `primary` и `secondary` корзины `codex`. Плагин не запускает задачи модели, не расходует лимит на генерацию и не читает токены авторизации самостоятельно. Авторизацию и запрос к сервису выполняет Codex CLI. Ответы сервера и stderr не записываются в журнал плагина.

Интеграция со строкой состояния использует [IntelliJ Status Bar Widgets](https://plugins.jetbrains.com/docs/intellij/status-bar-widgets.html).
